🎯 My approach

Мне нравится разбираться в системах на уровне ниже абстракции.

Если запрос работает медленно — интересно понять почему.

Если worker выполняется дважды — разобраться с race condition или логикой планирования, а не просто добавить ещё один if.

Если сервис падает — найти причину и сделать так, чтобы проблема не повторялась.

Именно поэтому мне интересен backend.
